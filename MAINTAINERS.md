| Maintainer | Role | Focus |
|---|---|---|

## Stewardship

Maintainers are responsible for:

- reviewing issues and pull requests
- triaging defects, security reports, and dependency risks
- keeping tests, quickstart, Docker setup, and CI healthy
- curating public benchmark fixtures and domain packs
- documenting releases and breaking changes

## Open Source Program Notes

Murmura is intended to be public source code with active maintenance signals: CI, tests, setup scripts, public fixtures, contribution guidelines, security reporting, and maintainer ownership.

Murmura uses AGPL-3.0-or-later, an OSI-approved strong copyleft license. Commercial use is allowed, while modified distributed or network-hosted versions must keep corresponding source code available under the same license terms.
